# Accessibility Audit Report

## ARIA & Contrast Audit
1. **Interactive Elements**: All tabs, buttons, sliders, and modal dismiss controls use native semantic `<button>` / `<input>` elements.
2. **Color Contrast**: Dark background with high-contrast text (`text-slate-100` on `#0b0f19`).
3. **Keyboard Navigation**: Focus outlines are visible on primary controls.
