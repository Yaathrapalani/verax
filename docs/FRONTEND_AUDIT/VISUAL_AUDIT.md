# Visual System Audit Report

## Visual Consistency Review
1. **Typography**: Inter / system font hierarchy with consistent weight scalings (text-xs to text-xl).
2. **Color System**: High-contrast dark industrial theme (slate background `#0b0f19`, glass cards with backdrop blur).
3. **Badges & Statuses**:
   - `PASS` / Operational: Emerald Green (`#10b981`).
   - `ABSTAIN` / Alert: Amber (`#f59e0b`) / Crimson (`#ef4444`).
   - `SIMULATED` / Counterfactual: Violet (`#8b5cf6`).
   - `UNAVAILABLE`: Slate Gray (`#64748b`).
4. **Interactive States**: Smooth hover transitions on buttons, interactive Three.js 3D viewport canvas.
