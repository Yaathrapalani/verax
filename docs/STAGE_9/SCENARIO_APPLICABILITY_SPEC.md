# Scenario Applicability Specification

## Classifications
- `SUPPORTED`: Valid thermal recalculations supported cleanly by Stage 5 Core.
- `PARTIALLY_SUPPORTED`: Scenario proceeds with applicability downgrade when baseline state was evaluated as ABSTAIN.
- `UNSUPPORTED`: Perturbation magnitude or model regime out of bounds.
- `UNAVAILABLE`: Hydraulic pressure/ΔP measurements unavailable in baseline dataset. System does NOT claim hydraulic consequences.
