## Strongly Typed Graph Edges

`EvidenceEdgeV2` links source and target nodes with typed relationship semantics.

### Edge Classifications (`GraphEdgeType`)
- `DERIVED_FROM`, `EXTRACTED_FROM`, `OBSERVED_IN`
- `MAPS_TO`, `DESCRIBES`, `MEASURES`, `BELONGS_TO`
- `DEPENDS_ON`, `USES_INPUT`, `USES_MODEL`, `USES_VERSION`, `USES_ASSUMPTION`
- `SUPPORTED_BY`, `CONSTRAINED_BY`, `PRODUCES`, `PREDICTS`, `HAS_UNCERTAINTY`
- `CHALLENGES`, `SUPPORTS`, `CONTRADICTS`, `INFLUENCES`
- `RESULTED_IN`, `APPROVED_BY`, `EVALUATED_BY`, `FOLLOWED_BY`
