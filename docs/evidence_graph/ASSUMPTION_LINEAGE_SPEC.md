## Assumption Lineage Tracking

Engineering assumptions (e.g. `counter-current exchanger assumption`, `initial-window UA reference baseline`) are represented as explicit `ASSUMPTION` nodes and linked via `USES_ASSUMPTION` edges to prevent assumptions from being passed off as observed facts.
