## 1. Mission & Purpose
Given admissible evidence at evaluation timestamp $T$, the Engineering Core determines which engineering quantities can legitimately be calculated, how they were calculated, which assumptions and physical constraints apply, whether the resulting state is physically consistent, and exactly what evidence supports the result.

### Core Chain
$$\text{EVIDENCE} \rightarrow \text{TEMPORAL VALIDITY} \rightarrow \text{DIGITAL SHADOW} \rightarrow \text{EVIDENCE GRAPH} \rightarrow \text{ENGINEERING COMPUTATION} \rightarrow \text{ENGINEERING STATE} \rightarrow \text{RECONCILIATION} \rightarrow \text{EVIDENCE GRAPH}$$
