# PLANT-X Information Architecture

## Top-Level Navigation Routes
1. `/plant` — Plant Overview & Process Topology
2. `/process` — Interactive Process Engineering & PFD Schematic
3. `/simulation` — Scenario & Counterfactual What-If Workbench
4. `/evidence` — Evidence Graph & Diagnostic Hypotheses
5. `/studies` — Case Comparison & Benchmark Scorecard
6. `/validation` — Model Identity & Provenance Verification

## Secondary Contextual Tabs (Engineering Inspector)
- `ASSET`: Equipment identification and mechanical specs
- `STREAM`: Flow rates, temperatures, pressures
- `THERMODYNAMICS`: State properties, phase, property package
- `FOUL-X`: Degradation forecast, RUL, Trust Gate status
- `PROVENANCE`: Cryptographic hash chain
- `BENCHMARK`: Model accuracy vs baseline
