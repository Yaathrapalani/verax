# PLANT-X Frontend 2.0 Design System

## Palette & Color Tokens
- `bg-workstation`: `#090d16` (Deep industrial slate)
- `bg-surface`: `#111827` (Panel background)
- `bg-surface-elevated`: `#1f2937` (Hover/card elevation)
- `border-subtle`: `#1f2937`
- `border-strong`: `#374151`
- `text-primary`: `#f9fafb`
- `text-secondary`: `#9ca3af`
- `text-muted`: `#6b7280`

## Universal Status Tokens
### Data Truth States
- `OBSERVED`: Teal / Cyan `#0d9488`
- `DERIVED`: Blue `#2563eb`
- `SIMULATED`: Violet `#7c3aed`
- `ASSUMED`: Amber `#d97706`
- `REPRESENTATIVE`: Slate `#64748b`
- `UNRESOLVED`: Dark Orange `#ea580c`
- `UNAVAILABLE`: Muted Gray `#4b5563`

### Validation States
- `VALID`: Emerald Green `#059669`
- `VALID_WITH_WARNINGS`: Yellow `#ca8a04`
- `INVALID`: Red `#dc2626`
- `OUT_OF_SCOPE`: Purple `#9333ea`

### Trust Gate States
- `PASS`: Green `#16a34a`
- `ABSTAIN`: Amber `#d97706` (Triggers Fixed-Policy Fallback)

### Model Identity
- `PRODUCTION`: Emerald `#059669`
- `BENCHMARKED`: Cyan `#0891b2`
- `RESEARCH_PROTOTYPE`: Violet `#7c3aed`
- `UNVALIDATED`: Gray `#4b5563`
