# Evidence Workspace Specification

The Evidence Workspace exposes Stage 4 Evidence Graph and Stage 8 Investigation Intelligence.

## Components & Flow
- **Hypothesis Matrix**: Competing hypotheses H1–H5 with confidence scores.
- **Lineage Graph**: Directed graph mapping raw sensor readings $\rightarrow$ physics derivations $\rightarrow$ FOUL-X prognosis $\rightarrow$ Trust Gate $\rightarrow$ Advisory Decision.
- **Trace Modes**: "Trace Why" (causal antecedent) and "Trace Impact" (downstream effect).
