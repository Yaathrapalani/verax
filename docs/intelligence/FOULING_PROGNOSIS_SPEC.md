# Fouling Prognosis Specification

## Overview
`FoulingPrognosis` is the formal forecast contract generated by Stage 6.

## Contract Schema
- `prognosis_id`: Unique identifier.
- `asset_id`: Exchanger identifier.
- `timestamp`: Origin timestamp \(T\).
- `horizon_hours`: Forecast horizon (1h, 6h, 24h).
- `target_definition`: `R_f_derived(t+h)`.
- `prediction`: Projected float value or `None`.
- `model_id`: Model identifier (`Persistence`, `RecentTrend`, `Ridge`).
- `model_version`: SemVer string (`1.0.0`).
- `feature_version`: SemVer string (`1.0.0`).
- `input_window_hours`: Context window depth (168h).
- `training_scope`: `synthetic physics-based benchmark`.
- `evaluation_scope`: `Validation split t=44,800..54,399`.
- `status`: Status enum (`AVAILABLE`, `INSUFFICIENT_HISTORY`, `INVALID_INPUT`, `UNAVAILABLE`).
- `baseline_reference`: Dictionary containing benchmark persistence predictions.
- `uncertainty_status`: Explicit boundary `NOT_IMPLEMENTED`.
- `mechanism_claim`: Explicit boundary `NONE`.
- `provenance`: Immutable calculation provenance.
