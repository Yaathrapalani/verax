## Typed Process Topology

Represents physical and functional relationships using Stage 0 `PlantGraph` models.

### Relationship Types
- `CONNECTED_TO`
- `FEEDS`
- `RECEIVES`
- `MEASURES`
- `HAS_EVENT`
- `DEPENDS_ON`

Relationships missing explicit evidence are NEVER fabricated.
