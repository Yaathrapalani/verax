# False Positive / False Negative Specification

## Definitions
- **TP**: Intervention when future degradation meets maintenance criterion.
- **FP**: Intervention when future degradation does not meet criterion.
- **FN**: No intervention when future degradation meets criterion.
- **TN**: No intervention when future degradation does not meet criterion.
- Metrics calculated: Precision, Recall, Specificity, FPR, FNR, F1 score.
