# Trust Engine Specification (Stage 7)

## Purpose
The Stage 7 Trust Engine establishes a scientifically defensible permission boundary between machine predictions (`FoulingPrognosis`) and consequential maintenance actions.

## Core Principle
"THE MODEL DOES NOT EARN TRUST BY PRODUCING A PREDICTION. IT EARNS TRUST BY SURVIVING CHALLENGE."

## Pipeline
1. Data Trust
2. Sensor Validity
3. Physical Consistency
4. Historical Regime Support
5. Predictive Uncertainty & Calibration
6. Reliability Gate Decision (`TRUSTED` or `ABSTAIN`)
